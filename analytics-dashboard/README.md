# Business Analytics Dashboard

Interactive analytics dashboard connected to Supabase.

## Capabilities

- Multi-dimensional filters
- Revenue, order, customer and AOV KPIs
- Revenue and customer trends
- Branch and service performance
- Campaign analysis entry points
- AI recommendation workflow triggers
- CSV / spreadsheet export

## Local setup

1. Copy `.env.example` to `.env`.
2. Add your own Supabase project values.
3. Add optional n8n/advisory URLs.
4. Run:

```bash
npm install
npm run dev
```

The production dataset is not included.
